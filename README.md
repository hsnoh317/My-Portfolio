# My-Portfolio

Personal portfolio site for Huiseung Noh — a single static page (`index.html` + `styles.css`) with Projects, About and Contact sections.

## View it

Open `index.html` in a browser. No build step or dependencies.

## Add a project image

Put the image in `images/`, then inside a `.project-image` block in `index.html` add:

```html
<img src="images/your-file.jpg" alt="Describe the work">
```
